**Why these numbers differ from the TF-IDF runs above:** only the semantic
component changes. Embedding cosine similarities for related texts are
higher than TF-IDF cosines, so after the same rescaling the semantic scores
(and therefore the overall scores) come out higher, and a few mid-table
candidates swap places. The scoring formula, skill coverage, experience
scores and ranking logic are exactly the same, and the top and bottom of
the table are unchanged — the specialist is still #1 and the fresher is
still last. This is the run shown in the README screenshots.
